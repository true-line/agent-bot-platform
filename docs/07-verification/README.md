# Verification

The testing half of the lifecycle: what is tested, at which level, by whom, and what evidence a stage needs to exit. The platform specifies tests; soul-conformance implements and runs them.

| Page | Contents |
|---|---|
| [Test strategy](test-strategy.md) | Test levels, stage entry and exit, independence, evidence, environments |
| [Conformance catalog](conformance-catalog.md) | T01 to T30 by stage, generated from `registry/tests.yaml` |

Stage test plans and test reports are written from the templates when a stage starts; each cites the T-series IDs it covers.
