# Requirements

What the platform must do and how well, with every requirement traced to the tests that prove it. Requirement wording lives in `registry/requirements.yaml`; the pages here are generated from it or analyze it.

| Page | Contents |
|---|---|
| [Product requirements](product-requirements.md) | R1 to R12, generated from the registry |
| [Quality attributes](quality-attributes.md) | Security, privacy, intelligence, accuracy and extensibility: coverage and gaps |
| [Traceability matrix](traceability-matrix.md) | Requirement to test to stage, and tests with no requirement, generated |

Every "must" or "never" in a platform page, a contract or a component design traces to an R or QA requirement. A statement that cannot be traced is design guidance, not a requirement.
